# Logo Assets

Place the BARCODE SPIN logo assets in this directory.

Expected files:
- `barcode-spin-logo.png` - Main logo (recommended: 512x512px or larger)
- `barcode-spin-logo.svg` - Vector version (if available)

The logo from the project spec should be saved here and will be used:
1. In the header (top-left)
2. As the favicon/app icon

For now, a placeholder is used in the header.
